Layer 0 · Ambient

What every session — and every subagent — loads

~/.claude/CLAUDE.md is injected into the main session and into every persona's context. settings.json pins three defaults that would otherwise silently undo the design.

CLAUDE.md — eight rules each names the failure it catches

  1. Think before coding — ask only when ambiguity changes contracts, schema, security, or is irreversible
  2. Simplicity first — nothing speculative
  3. Surgical changes — inspect git diff --cached before every commit
  4. Goal-driven execution — cheapest meaningful verification per change type
  5. Deterministic before probabilistic — plain code where if/else suffices
  6. Surface conflicts, don't average them
  7. Fail loud — "couldn't check" never reads as "works"
  8. Modules communicate through contracts — never import another module's internals; a missing contract is a blocker

Plus sections on session/context hygiene (caveman chat mode), worktrees (one per ticket, .claude/worktrees/, runtime isolation warning), agent orchestration (packets, no persona-to-persona dispatch, parallel when safe), models (persona defaults, escalate upward only), and the durable-records split (IDEAS.md / adr/ / MEMORY.md).

settings.json — enforcement pins env

CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1no subagent can spawn another; "personas never dispatch personas" is structural
CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=0a named subagent never becomes a teammate (which would drop worktree isolation and ignore skills:)
CLAUDE_CODE_FORK_SUBAGENT=0no conversation forks that inherit the full context and tool pool; restores run_in_background control to /build
